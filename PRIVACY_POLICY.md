# Hana Bot Privacy Policy

**Last updated:** 12 September 2026

This Privacy Policy explains how Hana ("Hana", "the Bot", "we", "us") processes personal information when used on Discord. It applies to Hana's conversational AI, optional memory, voice text-to-speech, roleplay features, status updates, and mini-games.

## 1. Information Hana processes

Hana processes only information needed to provide its features:

- **Discord identifiers and context:** user ID, display name/username, server ID, channel ID, and interaction data needed to respond to commands and operate a feature.
- **RoomAI messages:** message content and the display name of the sender in a channel where a server administrator has explicitly enabled RoomAI.
- **Conversation memory:** when RoomAI is used, Hana keeps up to 16 recent message lines for a user until it creates a concise memory summary. It may also retain up to 12 user statements that indicate an important personal preference or fact (for example, a nickname, a preference, or an ongoing concern). This is used only to make future RoomAI replies more coherent.
- **Room context:** RoomAI keeps up to 16 recent user/Hana chat messages for each enabled channel so it can respond to the current conversation. Disabling RoomAI stops replies but does not automatically erase the saved context.
- **Temporary activity and game data:** a shared roleplay activity records the channel ID, participant display name, activity, and expiry time for up to 25 minutes. Mini-game sessions contain the Discord user ID, chosen answers, and game state in memory and expire after a short period.
- **Voice text-to-speech input:** if a server administrator has placed Hana in a voice or stage channel, text sent in that channel may be used to generate spoken audio.

Hana does not ask for or intentionally collect Discord passwords, authentication tokens, payment-card details, precise location, or similar highly sensitive information. Please do not submit them to the Bot.

## 2. How information is used

We use the information above to answer commands and messages, preserve optional conversation continuity, generate AI responses and spoken audio, run mini-games and temporary shared activities, prevent misuse, troubleshoot errors, and maintain the Bot. We do not sell personal information, run targeted advertising, or use Discord API data to profile users or their relationships.

## 3. When information is shared

Information is shared only as needed to deliver the feature you use:

- **Discord** receives and transmits messages and interactions as part of its platform.
- **Google Gemini** receives RoomAI prompts, which can include the applicable message, relevant room context, and relevant memory, to generate an AI response. It may also receive recent lines when Hana generates a memory summary.
- **Google Translate Text-to-Speech** receives text submitted for the optional text-to-speech feature in order to create audio.

These providers process information under their own terms and privacy practices. We do not sell or disclose Discord API data to data brokers, advertising networks, or other unrelated third parties.

## 4. Storage and retention

Hana stores its operational data locally with the Bot operator:

- Room context is limited to the latest 16 messages per RoomAI channel.
- Pending memory lines are summarized after 16 lines. The resulting summary (maximum 1,000 characters) and up to 12 pinned memory items can remain until changed or deleted.
- A shared activity expires automatically after 25 minutes.
- Mini-game sessions are held in memory for a short session and are not intended to be permanent records.

We retain information only for as long as it is reasonably needed to operate Hana, resolve issues, comply with law, or until a valid deletion request is fulfilled. The Bot operator may delete data sooner.

## 5. Your choices and deletion requests

You can avoid RoomAI by not sending messages in an enabled RoomAI channel and can avoid voice text-to-speech by not sending text in an active Bot voice/stage channel. A server administrator can disable RoomAI or remove Hana from a server.

To request access, correction, or deletion of data associated with your Discord account, contact **wati23rt@gmail.com** and include your Discord user ID, the relevant server/channel if known, and the nature of your request. We may ask for reasonable information to verify the request.

## 6. Security

We use reasonable administrative and technical measures intended to protect stored data. No online system is completely secure, so do not send sensitive information to Hana.

## 7. Children

Hana is not intended for anyone below the minimum age required to use Discord in their jurisdiction. We do not knowingly collect personal information from people who are not permitted to use Discord.

## 8. Changes to this policy

We may revise this policy when the Bot's features or applicable requirements change. The current version will show its update date at the top of this page.
